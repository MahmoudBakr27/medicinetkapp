Medicine Safety Checker

A simple Python desktop application built with **Tkinter** that provides basic medicine safety information based on common health conditions such as **diabetes, high blood pressure, and kidney disease**.

The application uses a CSV-based medicine database and checks the selected medicine against the user's entered health conditions to provide basic warnings and recommendations.

**Disclaimer:** This application is an educational programming project. It is **not a medical diagnostic tool** and should not be used to determine whether a medicine is safe for a specific person. Always consult a doctor or pharmacist for medical advice.

Features

- Search for a medicine by name
- Check considerations related to diabetes
- Check considerations related to high blood pressure
- Check considerations related to kidney disease
- Displays caution warnings when relevant
- Provides basic information about each medicine
- Uses a CSV file as the medicine database
- Simple desktop interface built with Tkinter
- Clear/reset functionality

Technologies Used

- **Python**
- **Tkinter** – Graphical User Interface
- **CSV** – Medicine database
- **Git & GitHub** – Version control


Database

The application currently uses a CSV file containing information about common medicines and their basic considerations related to:

- Diabetes
- High blood pressure
- Kidney disease
- Medicine class
- General notes
- Recommended action

The database is designed to be expandable, so additional medicines and medical considerations can be added later.
